# Mobile-CV

Fully responsive, mobile-first personal CV / portfolio website for Megan
Meyer, built with semantic HTML5, Bootstrap 5, and vanilla JavaScript (no
jQuery). Styles are written mobile-first (base rules target small screens,
`min-width` media queries layer up for tablet/desktop) and the markup follows
WCAG 2.1 AA practices: skip link, logical heading order, visible focus
states, sufficient colour contrast, `prefers-reduced-motion` support, and
accessible names for icon-only links.
